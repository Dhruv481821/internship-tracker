# Internship Tracker

A full-stack Internship Tracker built using Java, HTML, CSS, JavaScript, and MySQL.

## Features

- Add internships
- Update application status
- Delete records
- Search internships
- Responsive UI

## Tech Stack

- Java
- HTML
- CSS
- JavaScript
- MySQL
- JDBC

## Installation

1. Clone repository
2. Import into VS Code/IntelliJ
3. Add MySQL Connector
4. Configure database
5. Run Main.java
